# Support

Video Redactor is an open-source public beta maintained on a best-effort basis.

Use GitHub Issues for reproducible bugs and focused feature requests. Before
posting, search existing issues and review the troubleshooting and configuration
documentation. Security vulnerabilities belong in a private report described
by [SECURITY.md](SECURITY.md).

Never upload real payment-card video, unredacted screenshots, OCR transcripts,
private paths, or recognized values. Use the generated synthetic corpus and
sanitized reports to demonstrate problems.

Useful documentation:

- [Configuration and reports](docs/CONFIGURATION.md)
- [Testing](docs/TESTING.md)
- [HTTP API](docs/API.md)
- [Release and acceptance](docs/RELEASE.md)

The project does not currently promise response times, hosted processing, or
compliance certification.
